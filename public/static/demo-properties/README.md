# Demo property illustrations

Original vector illustrations created for the Straw & Pasture demonstration. No third-party
photography, real property imagery, or uploaded design references are embedded in these assets.

Each SVG is the editable source for its matching 1200 × 800 PNG, rendered from the vector artwork. The PNGs
are suitable for upload to the Sharetribe Test marketplace. Each image visibly states
“DEMO PROPERTY” and “Illustration · Not an available property.” Keep the demo label in listing
titles and descriptions as well, since image crops can hide text.

| Filename stem | Illustrated example |
| --- | --- |
| `palmetto-pasture` | Open pasture, horses, and a rail fence |
| `cedar-rail-stables` | Barn stalls, horse, and stable approach |
| `lowcountry-grazing` | Cattle grazing on open lowland pasture |
| `blue-ridge-shelter` | Run-in shelter, horse and cattle, mountain backdrop |
| `sandhills-pasture` | Wide cattle pasture and crossing fence line |
| `foothills-barn` | Boarding barn, horse, and wooded foothills |

These are fictional scenes for test data. They do not establish actual facilities, property
conditions, availability, or animal-care services. Replace them with host-authorized property
photos for genuine marketplace listings.
